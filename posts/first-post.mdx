# Ones and Zeros
A common problem is to find possible combinations of a set S. Sounds easy enough in most cases.
When the combinations you need to find should be unique, you have to find all subsets. This set of subsets is finite and called a powerset.
The powerset has cardinality 2^n, where n is the number of elements in the set S and the empty subset {} is included.
This fact is very intuitive if you consider each element of the set S to either exist or not exist in the subset. And this happens twice for each element n times.
It's all ones and zeros. And each subset is just a mapping of each element to a 1 or 0.
